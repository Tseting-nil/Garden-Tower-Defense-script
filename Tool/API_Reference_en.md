# Garden Tower Defense (GTD) API Reference

Automation and replay API for Garden Tower Defense. Scripts generated by the Placement Tracker call this API to reproduce in-stage actions, lobby setup, and farming routines.

> [!NOTE]
> - Load via Key System: `loadstring(game:HttpGet("https://raw.githubusercontent.com/Tseting-nil/Garden-Tower-Defense-script/refs/heads/main/%E5%AF%86%E9%91%B0%E7%B3%BB%E7%B5%B1.lua"))()`
> - Loading the Key System returns the global `GTD` table; you can also check `getgenv().GTD` or `getgenv().GTDAPI` to verify whether it is already loaded.

## 2. Game-End Detection

| API | Return Type | Description |
| :--- | :--- | :--- |
| `GTD.IsGameOver()` | `boolean` | Primarily checks `workspace.GameEndTime` attribute (server-authoritative, unaffected by UI panels); falls back to `GameEnd.Visible` |
| `GTD.IsGameEndVisible()` | `boolean` | Checks `GameGui.Screen.Middle.GameEnd.Visible` only |
| `GTD.GetGameResult()` | `"victory" \| "defeat" \| "unknown"` | Reads `Victory/Defeat.Visible`, falling back to `BaseHP <= 0` when UI is obscured |

### AutoReplay Flow
1. Waits for stage end (`GameEndTime` attribute or `GameEnd.Visible`, via event + polling).
2. Evaluates and records Victory / Defeat.
3. Waits up to 12s for `GameEnd.Items.Frame.Actions.Visible == true` (restarts directly if obscured).
4. Invokes `RestartGame:InvokeServer()` (up to 3 retries).
5. Waits for `GameStartTime` to update, confirming the new match has started.

## 3. Action Queue & Stage Controls

Queue actions using `GTD.Add*`, then call `GTD.ExecuteQueue()` to execute them in order once the match starts.

- **Gate parameter (`gate`)**: `number` = elapsed seconds after match start; `string` = cash threshold (e.g. `"$500"`, waits until Cash is sufficient).

| API | Description |
| :--- | :--- |
| `GTD.AddPlaceTower(unitId, gate, x, y, z, rotation [, pathIndex, distanceAlongPath])` | Queues unit placement and returns an incrementing `order` ID for upgrade/sell references. Omit `pathIndex`/`distanceAlongPath` for normal towers; provide them for path-based towers (e.g. `unit_wheel_bush`). |
| `GTD.AddUpgradeTower(order, gate)` | Queues unit upgrade (retries after waiting for cash if initial attempt fails) |
| `GTD.AddSellTower(order, gate)` | Queues unit sell |
| `GTD.AddTowerAbility(order, gate)` | Queues unit ability activation for `order` |
| `GTD.AddSellAll(gate)` | Queues selling all placed units and clears current round `order` bindings |
| `GTD.AddSetTargeting(order, mode, gate)` | Queues changing a unit's targeting mode |
| `GTD.AddToggleAutoUpgrade(order, gate)` | Queues toggling auto-upgrade for a unit |
| `GTD.AddSkipWave(gate)` | Queues wave skip |
| `GTD.AddBuyPlot(plotId, gate)` | Queues buying an event plot (auto-equips scythe, pathfinds to the plot, waits for cash) |
| `GTD.AddSetAutoSkip(value, gate)` | Queues setting the Auto Skip toggle |
| `GTD.AddSetSpeed(speed, gate)` | Queues game speed change (`speed = 1 / 2 / 3`) |
| `GTD.AddEnd(elapsed)` | Marks recorded match end timestamp (seconds) so replay timing aligns with recording |
| `GTD.ExecuteQueue()` | Waits for match start and executes all queued operations |
| `GTD.StopQueue()` | Manually stops the currently running automation queue and replay loop (returns `boolean`) |
| `GTD.GetQueueElapsed()` | Returns elapsed seconds since match start, or `nil` if not started |
| `GTD.GetQueueRemaining()` | Returns remaining seconds until `AddEnd` timestamp (negative if exceeded), or `nil` |

### Immediate Controls & Auto-Replay

| API | Description |
| :--- | :--- |
| `GTD.SetAutoSkip(value)` | Immediately sets Auto Skip toggle |
| `GTD.ActivateAbility(...)` | Immediately activates a unit ability |
| `GTD.SetTargeting(...)` | Immediately sets unit targeting mode |
| `GTD.SellAll()` | Immediately sells all units |
| `GTD.AutoReplay(value)` | Enables or disables automatic replay after match end |
| `GTD.ResumeAutoReplay()` | Resumes the auto-replay monitor |
| `GTD.SetRetryOptions(...)` | Configures retry behavior |

## 5. Anti-Macro Jitter & Special Tower Cooldowns

### Anti-Macro Jitter (Enabled by Default)
Adds subtle timing and positional randomization to reduce heuristic macro detection on remote calls.

```lua
GTD.SetJitter(false) -- Disable all jitter
GTD.SetJitter(true)  -- Enable with defaults
GTD.SetJitter({
    actionDelayMin = 0.05,   -- Min random delay before each action (seconds)
    actionDelayMax = 0.35,   -- Max random delay before each action (seconds)
    placeOffsetStuds = 0.15, -- Horizontal placement jitter radius (studs), 0 = off
    pathDistJitter = 0,      -- Path distance jitter for path towers, 0 = off
})
```

### Cooldowns & Monitoring
- **Distance Protection (Auto-Approach)**: Tower placement (non-path towers), upgrade, sell, ability activation, and targeting mode changes automatically check distance to the target and walk closer if it exceeds `PlaceMoveRange` (default `70` studs).
- `GTD.SetSpecialTowerCooldown(unitId, cooldownSeconds)`: Sets or clears placement cooldown in game-time seconds (built-in default: `unit_ice_dragon = 10`; pass `nil` or `<= 0` to clear).
- `GTD.SetEquipToolOnPlace(enabled)`: Controls whether the unit Tool is automatically equipped before placement (default `true`).
- `GTD.StartMacroNerfMonitor()` / `GTD.GetMacroNerf()`: Starts or reads macro nerf monitor state.
